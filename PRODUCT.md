# Учёт аренды
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
Статические HTML, CSS и JavaScript. GitHub Pages, без сборки и серверных зависимостей. Отдельный проект, не часть Allaptevbot.
## Users
Сотрудники небольшой компании по аренде оборудования. Ежедневная выдача, возврат, ведение клиентов и тарифов. Основное устройство — iPhone.
## Product Purpose
Сохранить базу оборудования и клиентов, считать стоимость по фактическим календарным дням, выявлять просрочку и экспортировать данные.
## Capabilities and Constraints
Пять разделов: оборудование, клиенты, цены, история, статистика. Четыре дневных тарифа, бессрочная аренда. localStorage с миграцией; CSV UTF-8 BOM; резервная копия JSON. Данные разных устройств не синхронизируются в базовой версии. Облачный адаптер — будущая интеграция.
## Brand Commitments
Русский интерфейс, светлая деловая тема, серый фон, белые карточки, синий акцент. Зелёный — свободно, жёлтый — в аренде, красный — просрочка. Нижняя навигация на телефоне.
## Evidence on Hand
Настоящие данные и фотографии не предоставлены. Sony FX3 и тарифы из задания доступны только как явно обозначенные тестовые данные.
## Product Principles
Не терять данные при обновлении. Подтверждать удаление. Запрещать удаление объектов с активной арендой. Считать весь срок по одному тарифу соответствующего диапазона.
