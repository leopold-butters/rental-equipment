# Данные

Рабочая база сохраняется в localStorage браузера под ключом `rental-equipment.db`. Приложение не записывает данные в этот каталог или репозиторий.

Экспорт CSV и полная резервная копия JSON скачиваются на устройство. Для восстановления используйте JSON через настройки приложения. Фотографии и документы включены в JSON, но не в CSV.
